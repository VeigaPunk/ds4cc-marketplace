gkeep

Local post-it notes on the Omarchy bar. Click the chip, paste a note, save it. All notes lists every note as dd:mm [hh:mm] with a short summary. No sign-in and no network: notes live in a JSON file on your machine.

install

Install on Omarchy

Needs Python 3, python-gobject, and gtk4. The note window is a local GTK process.

Quattro bar (Omarchy plugin)

omarchy plugin add https://github.com/VeigaPunk/gkeep.git --enable

Waybar

git clone https://github.com/VeigaPunk/gkeep.git && cd gkeep && ./install.sh

install.sh backs up your Waybar and Hyprland config, links ~/.local/bin/gkeep, and adds custom/gkeep on signal 12 when that id is free. It never writes under ~/.local/share/omarchy/. Remove with ./uninstall.sh or omarchy plugin remove io.github.veigapunk.gkeep; your notes stay.

privacy

Local only

  • Notes are stored in $XDG_DATA_HOME/gkeep/notes.json (usually ~/.local/share/gkeep/).
  • No account, no sign-in, no calls to Google or any other network service.
  • The yellow card is gkeep's own post-it, set in JetBrainsMonoNL Nerd Font Mono.
