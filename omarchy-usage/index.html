Omarchy Usage Tray

One Waybar chip for live AI usage windows — Codex, Grok, Kimi, Cursor, and Alibaba Token Plan. Cycle providers on the bar; swap identities when a provider has more than one live store. Touches ~/.config/waybar/ only — never ~/.local/share/omarchy/.

one-liner

Install on Omarchy

Writes Waybar config (backup first), symlinks ~/.local/bin/ai-usage, enables a 5-minute user timer, floats the TUI on Hyprland like other Omarchy TUIs.

curl -fsSL https://raw.githubusercontent.com/VeigaPunk/omarchy-usage-tray/main/install.sh | bash

Re-run the same line to update. Local clone: git clone https://github.com/VeigaPunk/omarchy-usage-tray.git && cd omarchy-usage-tray && ./install.sh

Bar clicks

GestureAction
Left-clickNext provider
ScrollCycle providers
Right-clickNext identity (Token Plan: team / gmail)

Token Plan right-click runs token-plan-swap toggle — flips ~/.config/alibaba-token-plan/active and rewrites ~/.bailian/config.json from the matching local key file. OAuth multi-account is a no-op until a provider has two live stores.
