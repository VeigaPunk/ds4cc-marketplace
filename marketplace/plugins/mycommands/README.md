# mycommands (marketplace plugin)

Tracks and installs **thin command-pack markdown** for recurring orch entrypoints (xbgst / xbreed family aliases).

## Honest scope

- Ships skill `mycommands-docs` (list/copy command markdown).
- Source of command bodies may live in `VeigaPunk/mycommands` (aliases) and/or host plugins such as **xbgst-stack**.
- Does **not** claim a large catalog of unrelated shell automations unless those files are present under `commands/`.

## Install

Via DS4CC / grok marketplace as plugin `mycommands`. See skill `mycommands-docs`.
