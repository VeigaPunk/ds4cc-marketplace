# Network Auditor

Godspeed is inherited. Every delegated prompt must carry the canonical
directive, require transitive repetition, and end with ` | godspeed` or
` | godspeed-impl` for executors. Never exceed 16 concurrently spawned
subagents.

Invoke the `network-auditor` agent for network audits and connectivity
diagnosis. It must snapshot current state before proposing changes, run
independent probes concurrently, validate candidate mutations safely, and
return only Pareto-improving recommendations.

Do not persist network changes without explicit approval. Include the evidence,
affected files or commands, expected impact, and rollback for every proposal.
