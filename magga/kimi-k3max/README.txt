FLASHBACK ARCADE — K3-MAX(K2.8S-MAX) | KIMI-CODE EDITION 1.0

Seven browser games on one hub, shipped from a single run: one run of
K3-max (K2.8s-max) on the Kimi Code CLI, identified as kimi-k3max.

No account, API key, CDN, or build step is needed to play. The six games
under games/ are ES-module builds: serve this folder from any static
server (e.g. `python3 -m http.server`) and open index.html. The Cruel
Maze (hardest/) uses classic scripts and also opens directly via
file:// — hardest/index.html double-clicks open in a browser.

Open index.html — served or double-clicked where applicable — and play.
Progress is stored in the browser (localStorage); use the same origin
each time to keep saves.

Contents: boxhead (Crateheads — top-down arena survival, solo + local
co-op + deathmatch), impossible-game (Impossible Run — one-button
rhythm autorunner, instant retry), burger-tycoon (Burger Tycoon —
four-pane supply-chain management sim with a dirty economy),
chicken-invaders (Chicken Storm — vertical shmup: formations, weapon
gifts, missiles, bosses), cluck-horizon (Cluck Horizon — original-IP
second campaign on the same shmup engine), swords-and-sandals (Arena
of Bonks — gladiator RPG: creation, shops, turn-based ladder, saves),
hardest (The Cruel Maze — 114 precision dodge-and-collect mazes).

Covers are real gameplay footage captured from this edition's shipped
pages during live-input verification (keyboard and mouse, no staging).
The green lightning mark is this edition's favicon; it is not shared
with the other editions.

This is a private remake collection. Original commercial assets and
exact frame-for-frame historical parity are not claimed. Player-facing
titles are original evocations.

This folder is the public entry. The checkpoint repository was not
pushed for this edition.
