ARCADE NIGHTS — GROK47-HIGH-ON-CURSOR-CLOUD EDITION 1.0

Seven self-contained browser games on one hub, shipped from a single
run: grok-4.7 on a Cursor cloud agent, identified as
grok47-high-on-cursor-cloud.

No account, API key, CDN, or build step is needed to play — every game
page is the finished artifact, and the whole arcade opens directly via
file:// as well as from this folder on the web.

Open index.html — or serve the folder from any static server — and play.
Progress is stored in the browser (localStorage); use the same origin
each time to keep saves.

Contents: boxhead (endless arena survival, solo/co-op/deathmatch),
impossible (five rhythm tracks + practice), burger-tycoon (four-pane
satire economy), chicken-invaders (ten-chapter solar arc), cluck-horizon
(original-IP shooter on the same engine), swords-and-sandals (gladiator
RPG ladder), hardest (114 mazes).

Covers are footage captured from this edition's shipped pages during
live keyboard, mouse, and touch verification. The amber horizon mark is
this edition's favicon; it is not shared with the other editions.

This is a private remake collection. Original commercial assets and
exact frame-for-frame historical parity are not claimed. Player-facing
titles are original evocations.

This folder is the public entry. The checkpoint repository was not
pushed for this edition.
