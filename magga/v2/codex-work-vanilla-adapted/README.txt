SECOND WIND ARCADE
Seven complete browser games. All art, sound and code are bundled.

PLAY
1. Install-free hosting: put this folder on any static web server, including a
   subdirectory. Open index.html. It has no external runtime requests.
2. Local play with Node.js 22+: run `node serve.mjs` in this folder, then open
   http://127.0.0.1:4173 . No npm install or build is needed.
3. Deadlock Rooms LAN: run `node deadlock-host.mjs`, then follow its printed
   local-network address on both devices. See Deadlock-LAN.md for details.

A normal static server is recommended. Browsers restrict module loading from
file:// URLs; the included local server avoids that restriction.

YOUR PROGRESS
Progress and sound settings stay in your browser on this device. Clearing site
storage clears those saves. Different hosting folders keep separate records.
Use each game's settings for volume, mute and control help. Switching away
pauses active play. Touch buttons and drag controls are available on phones.

THE COLLECTION
Crown & Sand — turn-based gladiator campaign
Deadlock Rooms — solo, local co-op, versus and LAN survival
Starfall Flock — space-shooter campaign
Cluck Horizon — a second original campaign on the same shooter engine
Vector Vault — 114 precision chambers
Pulsebound — five one-button rhythm courses
Burger Tycoon — four-operation corporate satire

Original assets and implementation. No account, payment or external service.
