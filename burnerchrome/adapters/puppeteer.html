GPT-5.4-Pro extended thinking and Deep Research live only on the authenticated chatgpt.com surface. Codex CLI cannot target them.

Drops a prompt into your signed-in ChatGPT tab and exits. Does not poll or scrape the reply — Pro Extended and Deep Research run for minutes to hours. You read the answer in the tab.

chitchat needs agent-browser on PATH (fnm is the documented host). It types the prompt into #prompt-textarea, presses Enter, verifies the user-turn count incremented, and exits.

Commands

Pro extended

Deep Research
chitchat --model pro --deep-research "Survey post-quantum crypto 2026"
Web search mode

Limits

  • No response retrieval — by design. Read the tab.
  • Shares whatever chatgpt.com tab is open. Open New chat first for a fresh thread.
  • Tool modes (image / deep research / web search) apply to the next prompt only.
  • Prompts must carry public URLs or inline content — no local /home paths.

Flags and env

  • --model pro|thinking|instant
  • --deep-research
  • --web-search
  • --image
