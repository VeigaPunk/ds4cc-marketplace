03 — Why DS4CC

Quality is the product

No broken plugins. No unreviewed dumps. Every admission is checked by Rust and gated by a written curation policy.

Rust-validated

Every plugin passes automated structural and capability checks in the ds4cc-validator crate before it ever reaches the catalog.

Curation-gated

Admission and removal policies for utility, provenance, docs, licensing, and security. A living marketplace — not a junk drawer.

Host-agnostic skills

Actionable SKILL.md files with fenced commands. Paste into chat or install into Grok, Codex, Claude, Kimi, Crush, or OpenCode.

Agent Pip

A Rust dashboard that renders live tmux panes in Waybar with anchored latest output — watch your agents while they work.

Rust validator

No broken plugins, ever

The ds4cc-validator crate enforces schema, semver, required skill proofs, and structural integrity before a plugin can land in the catalog.

  • Schema & required files present
  • Actionable SKILL.md with fenced commands
  • Semver + host manifest consistency
  • CI-gated admission evidence

Curation policy

A living marketplace, not a junk drawer

Admission and removal criteria keep the catalog sharp — utility first, claims disciplined, security non-negotiable.

  • Utility — solves a real agent workflow
  • Provenance — clear authorship and history
  • Documentation — README + actionable SKILL.md
  • Licensing — open and redistributable
  • Security — no opaque network side effects
  • Evidence — installs cleanly across hosts
